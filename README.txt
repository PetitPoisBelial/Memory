MEMORY — PHOENIX VS T-REX — VERSION PWA iPHONE

1. Modifie la liste `mots` au début de game.js si nécessaire.
2. Héberge tout le contenu de ce dossier sur un hébergement HTTPS (GitHub Pages, Netlify, etc.).
3. Sur iPhone, ouvre l'adresse avec Safari.
4. Appuie sur Partager puis « Sur l'écran d'accueil ».
5. Lance ensuite Memory depuis son icône.

Le service worker met les fichiers du jeu en cache : après une première ouverture réussie, le jeu peut fonctionner hors connexion.

Important : ouvrir index.html directement depuis l'app Fichiers ne suffit pas pour installer correctement une PWA. Il faut servir le dossier via HTTPS (ou localhost pendant le développement).
